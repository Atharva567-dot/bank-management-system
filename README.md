🏦 Bank Management System
A simple Bank Management System built with Python and Streamlit to demonstrate Object-Oriented Programming (OOP), session management, and interactive web application development.

📌 Project Overview
This project is a beginner-friendly banking application where users can create bank accounts, check account details, deposit money, and withdraw money.
The project was developed to practice **Python OOP concepts** and understand how Python can be used with Streamlit to build interactive web applications.

🚀 Features
👨‍💼 Admin
- Create new customer accounts
- Set customer name, account number, and initial balance
- Prevent duplicate account numbers
- Change the bank name

 👤 User
- Check account details
- Deposit money
- Withdraw money
- Check for insufficient balance
- Receive account-not-found messages

 🐍 Python Concepts Used
This project demonstrates several important Python concepts:
- Classes and Objects
- `__init__()` constructor
- Instance methods
- Class methods using @classmethod
- Static methods using @staticmethod
- Object attributes
- Conditional statements
- Dictionaries
- Functions and methods
- Session state management
- Basic error handling

 🛠️ Technologies Used
- Python
- Streamlit
- Object-Oriented Programming (OOP)
